# House-price-prediction
## 📌 Description
This project predicts **house prices using Machine Learning** based on features such as area, bedrooms, bathrooms, location, and other property details.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 🤖 Algorithm
- Linear Regression
- Decision Tree Regression
- Random Forest Regression

## 🔄 Workflow
**Data Collection → Data Preprocessing → EDA → Model Training → Prediction → Evaluation**

## 📊 Evaluation
The model is evaluated using:
- R² Score
- MAE
- MSE
- RMSE
